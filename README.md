# Usrsctp

This is [usrsctp](https://github.com/sctplab/usrsctp) packaged for Zig.

API bindings are available for the needs of [WebRTC](https://github.com/zigouat/webrtc) project.

## Installation

First, update your `build.zig.zon`:

```bash
zig fetch --save git+https://github.com/zigouat/usrsctp.git
```
